# 线边仓物料查询

## 设计原则
- **模型 ID 固定**：12336 写死在 SKILL，禁止从记忆或工具读取覆盖
- **零计算**：所有字段值原样展示，不做任何推导或换算
- **全量展示**：无状态过滤条件，返回数据直接按剩余时长升序排列后展示

---

## 执行边界（⚠️ 强制）

- 查询完成后，**调用 format_feishu_card 后立即结束**
- **禁止**数据为空时自动扩展查询其他条件，直接报告"该条件下无线边仓物料数据"
- **禁止**未经用户要求追加趋势对比或额外指标
- **禁止**省略数据或加省略号

---

## 执行流程

```
Step 1：判断查询模式
  → 用户提到"瓶颈""可生产时间""最短时长""整线能跑多久" → 产线汇总模式
  → 其余场景 → 明细模式（默认）

Step 2：确定查询参数
  → 线体 / 料站位 / 模组 / 产品料号 / 物料编码：用户指定则传，否则不传（查全量）
  → 多值用英文逗号分隔，示例："S03,S04"

Step 3：调用模型
  get_idi_model_data(model_id=12336, ...)
  ⛔ model_id 固定为 12336，禁止替换

  【产线汇总模式】
  → 按 line_code 分组，每组取 sytm 最小的一条作为该产线瓶颈记录
  → 按各组最小 sytm 升序排列后输出

  【明细模式】
  → 全部数据按 sytm 升序排列：
      • 取前 5 条 → TOP5 明细卡片（逐条展示全字段）
      • 取前 10 条 → TOP10 表格

Step 4：自检（见下方清单），调用 format_feishu_card 输出结果

Step 5：⛔ 立即结束，禁止继续调用任何工具
```

---

## 模型与字段（固定，禁止替换）

| 用途 | model_id | 过滤条件 | 适用场景 |
|------|----------|----------|----------|
| 线边仓物料 | **12336** | 无（查全量） | 剩余时长、剩余数量 |

### 12336 模型字段

| API 字段名 | 中文含义 | 类型 |
|------------|----------|------|
| `line_code` | 线体 | string |
| `material_station` | 料站位 | string |
| `module_number` | 模组 | string |
| `product_no` | 产品料号 | string |
| `material_code` | 物料 | string |
| `quantity` | 剩余数量 | double |
| `update_time` | 更新时间 | string |
| `sytm` | 剩余时长_单位_h | double |

---

## 卡片格式

format_feishu_card 按查询模式输出不同结构。

---

### 产线汇总模式卡片（有"瓶颈"/"可生产时间"意图时）

每条产线一张卡片：

```
🏭 {line_code} 线  可生产时间：{sytm} h

  瓶颈物料
  {material_code}

  料站位              模组          产品料号
  {material_station}  {module_number}  {product_no}

  剩余数量：{quantity}       更新时间：{update_time}
```

**标注规则（追加在卡片末）：**
- `sytm` ≤ 0.5：🔴 紧急补料
- `sytm` ∈ (0.5, 4]：⚠️ 关注
- `sytm` > 4：不追加标注

底部注脚文本：`共查询 {产线数} 条产线，以上为各产线剩余时长最短的瓶颈物料`

---

### 明细模式卡片

输出分为**两个区块**，顺序固定：先 TOP5 明细，后 TOP10 汇总表。

---

### 区块一：TOP5 明细卡片（剩余时长最短的前5条，逐条独立展示）

每条记录单独一张卡片，共5张：

```
#1  物料                            线体
    {material_code}                 {line_code}

    料站位              模组          产品料号
    {material_station}  {module_number}  {product_no}

    剩余数量            剩余时长
    {quantity}          {sytm} h      ⚠️ 最紧缺

    更新时间：{update_time}
```

**标注规则：**
- `sytm` ≤ 0.5：该卡片末追加 🔴 紧急补料
- `sytm` ∈ (0.5, 4]：该卡片末追加 ⚠️ 关注
- `sytm` > 4：不追加标注

---

### 区块二：TOP10 汇总表格

使用**飞书原生 table 组件**（非 Markdown 表格），结构如下：

- 标题：`⏱️ 线边仓物料剩余时长 TOP10（按剩余时长升序）`
- 组件类型：`table`，列定义：

  | 列 key | 列标题 | 宽度策略 | 截断 |
  |--------|--------|----------|------|
  | `rank` | 排名 | auto | 否 |
  | `line_code` | 线体 | auto | 否 |
  | `material_station` | 料站位 | auto | 否 |
  | `module_number` | 模组 | auto | 否 |
  | `product_no` | 产品料号 | auto | 否 |
  | `material_code` | 物料 | **weighted / 自适应最宽** | **禁止截断** |
  | `quantity` | 剩余数量 | auto | 否 |
  | `sytm` | 剩余时长(h) | auto | 否 |
  | `update_time` | 更新时间 | auto | 否 |

- 行数据：TOP10 每行填入对应字段原始值，`material_code` **完整展示，不得省略或加省略号**
- 底部注脚文本：`共 {总行数} 条记录，以上为剩余时长最短的前10条`
