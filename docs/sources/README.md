# 参考文献与事实核验目录（Sources）

本目录用于支撑 `doc/post-train/index.md` 中所有**事实类**与**总结类**信息的可追溯性，便于后续快速核实、修订。

## 规则

1. **凡是事实类/总结类陈述，都必须有引用**：在正文句末追加脚注 `[^Sx]`。
2. **一个脚注对应一个来源条目**：脚注落在 `index.md`，来源条目落在本目录的 `sources.md`。
3. **来源条目必须包含**：
   - 标识符：`S1`、`S2`…（与脚注一致）
   - URL
   - 访问日期（YYYY-MM-DD）
   - 摘要（用 3–8 行概括“该来源能证明什么”，避免大段复制）
   - 关键摘录（可选，短句/要点；避免整段原文）
4. **不确定/内部信息**：用“待核实”标记，不得写成确定事实；并给出需要补充的证据类型。

## 文件

- `sources.md`：来源清单（唯一事实来源索引）。
- `artifacts/`：可选，用于保存截图、表格、PDF 关键页（注意合规与版权）。
